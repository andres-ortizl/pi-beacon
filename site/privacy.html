π Beacon

Privacy

Pi Beacon processes Pi session files and runtime state on your computer. It does not upload session data, use analytics, set cookies or open a TCP listener. The local API uses a private Unix socket. Manual release checks, and the disabled-by-default update timer when enabled, request only public release metadata from GitHub.

Local data

The optional SQLite index stays in your user cache directory. Live bridge files stay in your user runtime directory and are removed during normal Pi shutdown.

Website

This static website is hosted by GitHub Pages. It contains no analytics, advertising, forms or tracking scripts.
