Changelog

Version 1.1.0

Activity hierarchy, model analytics and a polished dashboard

Added

  • Overview, Activity and Models dashboard views.
  • Parent-session execution trees with nested subagents and explicit unattached-agent handling.
  • Seven-day daily cost history and per-response model rankings for cost, tokens, responses and sessions.
  • Manual update commands, an opt-in daily release timer and a cached dashboard update badge.
  • Retained SQLite aggregates with migration and safe rebuilds after rewrites or retention changes.

Changed

  • Reworked the Zen dashboard with fixed navigation, consistent spacing, clearer typography and the Pi Beacon green accent.
  • Replaced ambiguous daily cost columns with labelled horizontal bars and improved scroll affordances.
  • Updates now refresh every Quickshell configuration recorded by the installer while preserving config and cache.

Version 1.0.0

First stable release

Added

  • Live state for main Pi sessions and Pi subagents.
  • Deterministic names from explicit names, first prompts or project directories.
  • Session path, start time, last message time, model, thinking, context and usage metadata.
  • Persistent FastAPI and Granian service with uvloop, private Unix socket transport and SSE updates.
  • Async SQLModel and SQLite caching with Alembic migrations, rewrite detection and bounded retention.
  • Versioned JSON Schema contracts for the live bridge, dashboard and Waybar.
  • Waybar status with mathematical session count notation.
  • Configurable Quickshell dashboard with an overridable Zen theme.
  • Freedesktop completion, waiting and error notifications with an optional bundled sound.
  • Interactive one-command installation, updates and data-preserving uninstall.
  • Waybar service controls for start, restart, quit and login autostart.
  • Bounded JSONL index batches and bounded shutdown with active SSE subscribers.
  • Static GitHub Pages landing, privacy page, terms and custom 404.
